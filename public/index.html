🔒 AES Room Chat

End-to-end encrypted. The server only ever sees scrambled bytes.

How is this private?

Your browser derives an AES-256 key from the room code using PBKDF2 (100,000 iterations). Every message is encrypted with AES-256-GCM before it ever leaves your device. The Cloudflare Worker only relays the resulting ciphertext to other people in the same room — it has no key and cannot read your messages.

Because a 4-digit code has only 10,000 possibilities, treat this like a shared "room key," not a strong secret — anyone who guesses or is told the code can join and decrypt. Use it for casual private chat, not for anything highly sensitive.
