🔒 AES Room Chat

End-to-end encrypted, peer-to-peer. No custom server at all.

How is this private?

Your browser derives an AES-256 key from the room code using PBKDF2 (100,000 iterations). Finding other people in the same room uses a public matchmaking network (Trystero, over Nostr) — no server of ours is involved at all. Once two browsers find each other, every message is encrypted with AES-256-GCM and sent directly peer-to-peer over WebRTC (which is itself always encrypted too).

Because it's peer-to-peer, a handful of very restrictive networks (some corporate firewalls, some mobile carriers) can block the direct connection entirely. If that happens between two particular people, they simply won't be able to exchange messages with each other in this version.

Because a 4-digit code has only 10,000 possibilities, treat this like a shared "room key," not a strong secret — anyone who guesses or is told the code can join and decrypt. Use it for casual private chat, not for anything highly sensitive.
